Capítulo 27 Talleres y problem sets

Los talleres reúnen ejercicios conceptuales, demostraciones y aplicaciones computacionales. A diferencia de los ejercicios cortos al final de cada capítulo, estos problem sets integran varios temas y sirven para preparar parciales, discusiones en clase y trabajo autónomo.

La idea es estudiar por bloques. Primero se repasan los conceptos en el capítulo correspondiente; después se resuelven ejercicios integradores que obligan a conectar álgebra, interpretación y práctica computacional.

27.1 Cómo usarlos

  1. Lee primero los capítulos asociados al taller.
  2. Resuelve las partes conceptuales sin mirar apuntes durante el primer intento.
  3. En las partes computacionales, conserva el código y comenta cada resultado.
  4. Si el taller se asigna como evaluable, las fechas y el mecanismo de entrega se anunciarán por Teams y por correo.

Los enunciados están diseñados para que practiques razonamiento econométrico. No basta con entregar una fórmula o una salida de software: cada respuesta debe explicar qué se está estimando, bajo qué supuestos y cómo se interpreta.

Problem Set 5: Variable dependiente binaria y series de tiempo MPL, logit, probit, efectos marginales, ACF, PACF y AR 15, 14 Disponible

27.3 Recomendación de trabajo

  • Los problem sets no reemplazan los capítulos: los integran.
  • Las preguntas de demostración preparan para parciales.
  • Las preguntas aplicadas preparan para leer resultados empíricos.
  • Las preguntas computacionales deben resolverse con código reproducible.
